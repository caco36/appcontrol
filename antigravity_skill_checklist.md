- [ ] Confirmei se os arquivos a serem lidos/gravados estão no caminho absoluto correto (Projeto vs Cérebro local).

## 2. Validação Pós-Código (A Injeção Não é o Fim)
- [ ] O código foi inserido com sucesso? SIM.
- [ ] Mas o servidor que escuta esse código está ciente da mudança? (ex: o watcher do Vite não travou?)
- [ ] Há necessidade de recarregar, limpar cache ou reiniciar algo? Se sim, devo reportar IMEDIATAMENTE.
- [ ] Existe algum efeito colateral que essa alteração causa no sistema?

## 3. Adesão Estrita ao Guard Prompt
- [ ] Descrevi claramente o que entendi?
- [ ] Listei os arquivos exatos que vou tocar?
- [ ] Pedi o OK de Antonio e aguardei?

- [ ] Parei e esperei a aprovação ao invés de prosseguir no automático?

## 4. Omissão Zero
